## 🚀 Project Overview
This project aims to provide a centralized, web-based solution for managing and tracking project development and testing activities.  
It helps teams collaborate efficiently and maintain transparency throughout project execution.

Key objectives include:
- Simplifying project task tracking and reporting  
- Managing test cases and outcomes  
- Enhancing issue reporting and resolution workflow  
- Utilizing Frappe’s modular and database-backed environment  

---

## 🧩 Features
- Project and issue management modules  
- Fully web-based (no local Frappe Bench setup required)  
- Role-based access control  
- Simple dashboards for tracking project and test data  
- Jenkins pipeline integration for continuous deployment  

---

## 🛠️ Tech Stack
| Component | Description |
|------------|-------------|
| **Framework** | Frappe Framework |
| **Languages** | JavaScript |
| **Database** | MariaDB (handled through Frappe) |
| **Interface** | Frappe Web Platform |
| **CI/CD** | Jenkins Pipeline |

---

## ⚙️ How to Use
1. Log in to your **Frappe web workspace**.  
2. Access the **Project and Test Management App** module.  
3. Create or view existing projects.  
4. Add issues, assign tasks, and track progress.  
5. Manage test cases and view test reports.  
6. Optionally, integrate with Jenkins for automated deployment or version tracking.

> 💡 Note: This project does **not** require local Frappe Bench commands like `bench start` or `bench new-app`. All operations are done directly on the hosted Frappe environment.

---

## 🧪 Continuous Integration
This repository includes a **Jenkinsfile** for CI/CD automation.  
The Jenkins pipeline helps with:
- Version control synchronization  
- Automated build and deployment  
- Basic testing integration
